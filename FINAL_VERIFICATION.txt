✅ Ready for Production Use!

To run the server:
  python -m mtg_mcp.server

With Docker:
  docker build -t mtg-mcp .
  docker run -i mtg-mcp

With Claude Desktop:
  Add to MCP config:
  {
    "mcpServers": {
      "mtg-mcp": {
        "command": "python",
        "args": ["-m", "mtg_mcp.server"]
      }
    }
  }
